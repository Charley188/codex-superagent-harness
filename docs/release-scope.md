# 公开发布范围

本仓库是从运行工程按白名单导出的独立源码仓库，使用新的 Git 历史。原安装目录、运行数据库和正在运行的服务不迁移、不删除。

## 保留

- 当前框架、网页、Windows 启动器、Codex 进程适配。
- 原版上游源码、许可证、版本和哈希清单，以及适配差异。
- 被运行路径或认证调用的程序、回归测试和两份合成输入。
- 安装、测试、验收与运维说明。

## 排除

- 废弃 DAG、监督及简化设置草稿。
- 一次性 prepare/record/import 脚本及旧 demo 入口。
- 完整上游克隆、node_modules、构建产物、缓存和桌面二进制。
- 私人知识库与用户项目、本机配置、会话、工单、SQLite、日志和证书。
- 原工作区历史文档、内部迁移报告及本机绝对路径。

公开副本仅做安装适配：新增初始化与运维脚本、调整包名和测试入口；把依赖作者历史数据库的审计替换为可重复的来源哈希与合成配置审计。没有绕过实际 Codex 或框架验收门槛。不会把原安装的既往验收结果当作公开副本的认证。

后续发布前运行 `python tools/check_public.py`，检查 Git 跟踪文件是否混入运行目录、配置、二进制或常见凭据格式。检查只报告文件名，不打印密钥内容；它不能代替对新增材料的人工内容审核。
